Shadows

Flat by design — no shadow exceeds rgba(0,0,0,0.15). Cards are defined by a 1px inset hairline, not elevation.

Icons

Phosphor Icons (MIT license, free) — replaced the emoji placeholders (✎ ⚠️ 🔴 🟡 ✕) used in the first pass. The live app uses @phosphor-icons/react with a global IconContext default of weight="bold" for legibility on small screens; this page loads the equivalent @phosphor-icons/web font build via CDN so the same glyphs are checkable without a build step.

Weights

Bold is the app-wide default. Fill is used selectively for status icons (warnings) to read as "alert" rather than outline. Tab-nav icons switch outline → fill on the active tab.

Do / Don't

Do

  • Use 10px radius as the default for cards and nav surfaces; 32–9999px only for pills and badges.
  • Build card definition with a 1px inset border, not a drop shadow.
  • Reserve ember orange (#ff3e00) for inline links / demo-link text, never a filled button.
  • Set body text in Inter 400 at 16–17px, line-height 1.42–1.53.

Don't

  • Never use a drop shadow stronger than rgba(0,0,0,0.04) on cards.
  • Don't use link blue (#0086fc) as a filled CTA background.
  • Don't introduce gradients — strictly flat, hairline borders only.
  • Don't use alert red (#ff2b3a) outside destructive/error states.
